# 生物科研工作台 · 本机网页

**在线版：** https://youir.github.io/danta-bio-workbench/ （`main` 分支更新后重新构建 `dist` 并推送 `gh-pages` 分支即可同步）

面向生物领域科研博士的通用本机工作台。网页用于快速选择任务、整理启动语、查看流程方法。界面在本机运行，不会自动启动 agent、读取本地研究资料、同步 AI 对话或执行 Git 更新。

## 启动

Windows 双击 `启动工作台.bat`，macOS 双击 `启动工作台.command`。首次启动会安装依赖并打开本机浏览器。需要 Node.js 20.19 或更新版本。服务只绑定 `127.0.0.1`，不向局域网开放。也可以在此目录运行：

```bash
npm install
npm run start
```

浏览器打开 `http://127.0.0.1:5173/`。

## 页面结构

- **开始：** 写下一个研究问题，或打开选题、论文、PPT、组会准备 / 复盘、生物科研日报五个独立工作区。每项工作都有自己的可编辑草稿、启动语和文件名清单。
- **研究记录：** 展示接入状态；当前不读取本地研究资料，也不显示演示记录。
- **机制图：** 单独入口，也能从 PPT 工作区进入。输入简短需求后生成绘图启动语；“查看制作过程”展开五步方法说明。
- **文献与信息源：** 说明 RSS 来源与网页当前未连接的状态。
- **知识库：** 可选择本地知识库文件夹查看所选名称，但此原型不会扫描、读取、上传或写入资料。
- **检查更新：** 独立发布版未关联远程仓库时显示说明；如自行关联了 GitHub 仓库，可手动比较提交并复制更新指令。

## 当前数据边界

草稿、所选文件名和选择的知识库名称只保存在当前页面内存；刷新网页后清空。文件选择只保存名称，不读取文件正文。请在 AI 编程助手（如 Codex）对话中粘贴已确认的启动语继续协作。

## 开发与检查

```bash
npm install
npm run check
npm run start
```

导航和主要表单适配键盘及窄屏。
